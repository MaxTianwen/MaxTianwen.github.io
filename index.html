SELECTED WORK · 03 / 03

Hand-written team project · 2024

Delivery Routing

A team-built C application that assigns shipments to three fixed truck routes while respecting weight, volume and delivery constraints.

MY CONTRIBUTION

  • Wrote shipment validation, truck assignment and command-line input handling in C.
  • Contributed route-diversion logic and tests with a four-person team, comparing feasible routes before projected load.

IMPLEMENTATION

  • C++ tests
  • Visual Studio
View code ↗
Implementation notes

Delivery Routing & Shipment Management uses a 25 × 25 city grid and three fixed routes. The selector compares heuristic diversion lengths, then projected load. Built on a Seneca scaffold; three existing native test failures are documented in the repository.
